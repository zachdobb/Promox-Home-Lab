# Proxmox Home Lab

## Overview
This project documents my personal IT and cybersecurity home lab. I built this environment to gain hands-on experience with virtualization, networking, Windows Server, Linux, and system administration.

My goal is to develop practical IT skills and prepare for a career in cybersecurity.

## Hardware
- Lenovo ThinkCentre Desktop
- 16 GB RAM
- Netgear 8-Port Managed Switch
- Home Network Router

## Software and Technologies
- Proxmox VE — Virtualization platform
- Windows Server — Active Directory and domain controller
- Windows 11 — Client virtual machine
- Rocky Linux — Linux administration
- Tailscale — Remote access

## Home Lab Projects

### 1. Proxmox Virtualization
Installed Proxmox VE on a Lenovo ThinkCentre to create and manage virtual machines.

### 2. Windows Server and Active Directory
Set up a Windows Server virtual machine to practice domain administration and user management.

### 3. Windows 11 Virtual Machine
Created a Windows 11 VM for Windows administration and Active Directory practice.

### 4. Rocky Linux
Created a Rocky Linux VM to practice Linux commands, networking, and system administration.

### 5. Networking
Using a managed network switch to learn about IP addressing, DNS, DHCP, and network configuration.

### 6. Remote Access
Using Tailscale to remotely access and manage my home lab.
