# Home Lab Hardware

## Lenovo ThinkCentre — Proxmox Server

### Overview
I use a Lenovo ThinkCentre as my primary virtualization server for my IT and cybersecurity home lab.

### Hardware Specifications
- **Computer:** Lenovo ThinkCentre
- **Processor:** AMD Ryzen 3 PRO 5350GE
- **CPU:** 4 cores / 8 threads
- **RAM:** 16 GB
- **Storage:** To be documented
- **Hypervisor:** Proxmox VE 9.2.2
- **Boot Mode:** UEFI with Secure Boot

### Virtual Machines
- **VM 100:** Rocky Linux 9
- **VM 101:** Windows Server (DC-01)
- **VM 102:** Windows 11

### Purpose
This server allows me to practice virtualization, Windows Server administration, Linux, networking, and cybersecurity in a controlled home lab environment.
